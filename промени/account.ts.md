# Промяна в `src/routes/account.ts` — затворена дупка в достъпа

`GET /api/content` беше **публичен** и връщаше целия blob със съдържанието
на всички дисциплини. Тоест платеното съдържание се сваляше с един адрес,
без вход и без покупка.

Маршрутът вече изисква вход **и** админска роля:

```ts
router.get(
  '/content',
  authenticate,
  asyncHandler(async (_req, res) => {
    if (_req.user?.role !== 'admin') {
      return res.status(403).json({ /* … */ });
    }
    // … както преди
```

Blob-ът остава само за архив и за стария монолитен файл. Учебните екрани
ползват `/api/content/*` от новия маршрутизатор, където достъпът се
проверява тема по тема.

**Проверено на живо:**

| кой | резултат |
|---|---|
| анонимен | 401 |
| влязъл потребител | 403 |
| админ | 200 |
