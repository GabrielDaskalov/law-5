# Промени в `src/routes/content.new.ts`

## 1. Търсенето връщаше суров JSON

Откъсът беше `left(c.sections::text, 160)` — тоест началото на JSON-а на
конспекта. На екрана излизаше:

```
[{"title": "Изложение", "blocks": [{"text": "Неустойка. Правна…
```

Сега текстът на блоковете се сглобява и се връща човешки откъс около
намерената дума:

```sql
(SELECT string_agg(coalesce(b->>'text', ''), ' ')
   FROM jsonb_array_elements(c.sections) sec,
        jsonb_array_elements(sec->'blocks') b) AS body
```

## 2. Търсенето не проверяваше достъпа

Търсеше се само по заглавие, но резултатите идваха от **всички** дисциплини,
включително некупените. Сега заявката пуска само темите, до които този
потребител има право: купена дисциплина или безплатна тема от витрината.

Проверено: анонимен посетител получава `{"conspects":[],"cases":[],"flashcards":[]}`;
влезлият вижда само своите дисциплини.

## 3. Администраторът вижда всичко

Иначе трябваше да „купи“ всяка дисциплина, за да я редактира. Ролята вече е
сверена с базата в `authenticate`/`optionalAuth`, така че на нея може да се
разчита:

```ts
const isAdminReq = (req: Request): boolean => req.user?.role === 'admin';
```

Подава се на `assertTopicAccess` и `assertSubjectAccess`.
