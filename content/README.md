# Съдържание

Учебният материал, извлечен от стария монолит, плюс новия материал по
Облигационно право и скриптовете, с които се качва.

## Какво има тук

| папка / файл | какво |
|---|---|
| `data/` | извлеченото от стария монолит, по дисциплини — това внася `backend/scripts/import-content.ts` |
| `novi-materiali/` | новият материал по Облигационно право: конспект, тестове, казуси (JSON) |
| `gotovi/` | подготвените партиди по теми, готови за качване |
| `konspekt/` | конспектът по теми |
| `scripts/` | скриптовете за разчитане и качване |
| `karta-na-temite.txt` | съответствието „тема в документа → тема в платформата“ |

## Скриптовете

| скрипт | какво прави |
|---|---|
| `extract.mjs` | чете стария `pravo-academy-data.js` и произвежда `data/` |
| `razcheti-konspekt.py` | разчита конспекта от `.md` в структуриран JSON (секции, подзаглавия) |
| `kachi-konspekt.mjs` | качва конспекта в платформата (`--probno` показва какво ще стане, без да записва) |
| `kachi-temi.mjs` | качва подготвените теми (въпроси и казуси) — `--papka`, `--predmet`, `--probno` |
| `dobavi-lipsvashti-temi.mjs` | създава теми, които ги има в материала, но не и в платформата |
| `zapis-na-api.mjs` | записва отговорите на API-то за демонстрационния файл |
| `sglobi-demo.py` | сглобява `Law-plus-demo.html` — целият сайт в един файл, без сървър |

Всички смятат пътищата спрямо себе си. Backend-ът се търси в `../../backend`;
друга папка се задава с `BACKEND_DIR`. Скриптовете за качване искат работещ
сървър и `.env` на backend-а (за връзката с базата).

## Проверките на съдържанието

`Проверка-на-въпросите-и-казусите.md`, `Проверка-2-казуси-и-тестове.md` и
`Сравнение-на-двата-документа.md` описват какво е проверено в самия материал:
брой опции, еднозначност на верния отговор, разпределение на буквите, дължина
на верния отговор спрямо останалите, пълнота на полетата на казусите.

Това са проверки на **съдържанието**, не на кода — правени са, защото
въпрос с два верни отговора не е програмен дефект, но проваля изпит.
